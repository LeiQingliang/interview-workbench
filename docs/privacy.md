# 隐私与数据边界

本说明描述Interview Workbench应用本身的数据处理方式，不代替浏览器、GitHub或部署平台的隐私政策。

## 笔记保存在哪里

填写的练习笔记保存在当前浏览器的本地存储中。应用没有用于接收笔记的后端，也不提供账号或跨设备同步服务。

浏览器本地保存不等于加密保管。相同来源下运行的JavaScript，以及拥有相关权限的浏览器扩展，可能读取这些内容。共享设备上的其他使用者也可能通过同一浏览器看到笔记。

## 应用不做什么

应用代码默认不集成分析遥测，不把练习笔记发送给项目维护者。维护者不会因为你打开页面就自动获得笔记内容。

这个边界不涵盖部署平台的访问日志。访问GitHub Pages或其他托管站点时，平台可能处理IP地址、请求时间、浏览器信息等访问数据。打开外部参考链接、GitHub Issue或其他网站，也会产生与相应服务的交互。

## 哪些情况可能丢失笔记

- 清除网站数据、浏览器数据或无痕会话。
- 更换浏览器、设备或页面来源。
- 浏览器禁用或限制本地存储。
- 使用离线 `file:` 页面时遇到浏览器存储限制。
- 内容标识或存储结构发生不兼容变化。

请将需要长期保存的文字另行保存在自己信任的位置。浏览器状态不是备份，也不应成为唯一副本。

## 怎样删除

侧栏的 **清除本地记录** 会先请求确认，然后仅删除本工具的 `interview-workbench:v1` 存储项。建议先通过页面上方的导出按钮保存 Markdown 笔记。

通过浏览器的站点设置清除当前站点的本地数据。操作通常会一并移除该来源下的其他本地状态，应先确认要清除的站点。离线文件的存储行为取决于浏览器，可以在浏览器的数据管理界面检查。

删除本地笔记不会删除你已经主动复制、截图、提交到Issue或保存到其他位置的副本。

## 建议填写什么

填写脱敏的事件背景、个人动作、指标定义和练习反馈即可。不要输入密码、访问令牌、身份证件号码、完整客户名单、未公开合同或公司保密资料。涉及他人时使用角色称谓，删除可识别信息。

公开提交Issue或Pull Request前，请检查正文、附件、截图和浏览器错误输出。调试信息也可能包含输入内容。

## 离线文件的信任

单文件HTML可以包含可执行JavaScript。只使用可信来源的构建或自行构建的版本；文件能够离线打开，并不代表内容天然安全。不要随意打开声称能恢复笔记或提供额外功能的未知HTML文件。

## 内容本身

公共仓库与演示应只包含通用练习材料，不包含真实个人简历、联系方式或原始业务记录。发现意外公开的信息时，请按 [安全政策](../SECURITY.md) 联系维护者，并避免在公开讨论中重复粘贴相关信息。
